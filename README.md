# 🔐 Security Labs

Repositório dedicado à documentação de **laboratórios práticos de Cybersecurity**, realizados em ambientes controlados de treinamento.

O objetivo é registrar estudos práticos, técnicas de exploração, análise de vulnerabilidades, ferramentas utilizadas e resultados obtidos durante o processo de aprendizado em segurança da informação.

## 📚 Labs

### 🌐 Web Cache Deception

Laboratórios relacionados à análise e exploração de vulnerabilidades envolvendo mecanismos de cache, interpretação de URLs e discrepâncias entre o **Cache** e o **Origin Server**.

| Lab                                                                       | Descrição                                                                                                 | Status      |
| ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ----------- |
| [Lab 01 - Path Mapping](./web-cache-deception/lab-01-path-mapping/)        | Exploração de discrepâncias no mapeamento de caminhos entre cache e servidor de origem                    | ✅ Concluído |
| [Lab 02 - Path Delimiters](./web-cache-deception/lab-02-path-delimiter/) | Exploração de discrepâncias na interpretação de delimitadores de caminho entre cache e servidor de origem | ✅ Concluído |
| [Lab 03 - Origin Normalization](./web-cache-deception/lab-03-origin-normalizations/) | Exploração de discrepâncias na normalização de caminhos entre cache e servidor de origem | ✅ Concluído |
| [Lab 04 - Cache Server Normalization](./web-cache-deception/lab-04-cache-server-normalization/) | Exploração de discrepâncias na normalização do caminho entre cache e servidor de origem | ✅ Concluído |

## 🛠️ Competências praticadas

* Web Cache Deception
* Path Mapping
* Path Confusion
* Manipulação de URLs
* Análise de caminhos e delimitadores
* Análise de requisições e respostas HTTP
* Análise de HTTP Headers
* Análise de comportamento de Web Cache
* Burp Suite
* Burp Suite Intruder
* Identificação de discrepâncias entre Cache e Origin Server
* Identificação de recursos potencialmente cacheáveis

## 🎯 Objetivos

* Desenvolver habilidades práticas em Cybersecurity;
* Praticar identificação e exploração de vulnerabilidades em ambientes controlados;
* Aprimorar a análise de requisições e respostas HTTP;
* Desenvolver experiência com ferramentas de segurança;
* Documentar metodologias e resultados de forma técnica;
* Construir um portfólio prático de estudos em Cybersecurity.

## 📂 Organização

Os laboratórios são organizados por categoria.

Cada categoria possui seu próprio `README.md`, apresentando os laboratórios realizados e seus respectivos objetivos.

Cada laboratório possui sua própria documentação técnica e suas evidências visuais são mantidas separadamente.

## 📖 Plataforma

Os laboratórios são realizados em ambientes controlados de treinamento, principalmente na **PortSwigger Web Security Academy**.

## ⚠️ Disclaimer

Todos os testes documentados neste repositório foram realizados em **ambientes autorizados e controlados**, destinados ao aprendizado e treinamento em segurança da informação.

As técnicas apresentadas devem ser utilizadas somente em sistemas próprios, ambientes de laboratório ou sistemas para os quais exista autorização explícita para testes de segurança.
