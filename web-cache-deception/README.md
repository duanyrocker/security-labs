# Web Cache Deception

Labs práticos sobre vulnerabilidades de **Web Cache Deception**, realizados no PortSwigger Web Security Academy.

Os estudos desta categoria abordam diferentes formas de explorar discrepâncias entre o comportamento do **Cache** e do **Origin Server** durante o processamento de URLs.

## Assuntos estudados

| Assunto | Descrição | Status |
|---|---|---|
| [Path Mapping](./lab-01-path-mapping/) | Exploração de discrepâncias no mapeamento de caminhos entre cache e servidor de origem | ✅ Concluído |
| [Path Delimiters](./lab-02-path-delimiter/) | Exploração de discrepâncias na interpretação de delimitadores de caminho entre cache e servidor de origem | ✅ Concluído |
| [Origin Normalization](./lab-03-origin-normalization/) | Exploração de discrepâncias na normalização de caminhos entre cache e servidor de origem | ✅ Concluído |
| [Cache Server Normalization](./lab-04-cache-server-normalization/) | Exploração da normalização realizada pelo servidor de cache | ✅ Concluído |

## Competências praticadas

- Análise de comportamento de Web Cache
- Identificação de discrepâncias entre Cache e Origin Server
- Path Mapping
- Path Delimiters
- Path Normalization
- Análise de regras de cache para diretórios estáticos
- Manipulação e análise de URLs
- Análise de requisições e respostas HTTP
- Burp Suite

## Estrutura

Cada assunto possui seu próprio diretório, contendo a documentação e os materiais relacionados aos laboratórios correspondentes.

As **evidências visuais** e os **relatórios técnicos** são mantidos separadamente dentro de cada assunto.
