# Web Cache Deception

Labs práticos sobre vulnerabilidades de **Web Cache Deception**, realizados no PortSwigger Web Security Academy.

## Labs realizados

| Lab                      | Descrição                                                                                                 | Status      |
| ------------------------ | --------------------------------------------------------------------------------------------------------- | ----------- |
| Lab 01 - Path Mapping    | Exploração de discrepâncias no mapeamento de caminhos entre cache e servidor de origem                    | ✅ Concluído |
| Lab 02 - Path Delimiters | Exploração de discrepâncias na interpretação de delimitadores de caminho entre cache e servidor de origem | ✅ Concluído |

## Competências praticadas

* Análise de comportamento de Web Cache
* Path Mapping
* Path Confusion
* Análise de delimitadores de URL
* Manipulação de caminhos e URLs
* Análise de requisições e respostas HTTP
* Análise de headers de cache
* Burp Suite
* Burp Suite Intruder
* Identificação de discrepâncias entre Cache e Origin Server
* Identificação de recursos e extensões potencialmente cacheáveis
* Validação de comportamento `Cache-Control`, `Age` e `X-Cache`

## Evidências

As evidências visuais e o processo de exploração de cada laboratório estão documentados separadamente nos respectivos arquivos de evidências.

Os relatórios técnicos descrevem a metodologia, análise, exploração e resultados obtidos em cada laboratório.
